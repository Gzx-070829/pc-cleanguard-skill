# Privacy Policy

## Offline Mode

仅使用调用方提供的本地元数据，不联网、不上传。PR1 只实现 Offline Mode 的文档和策略模型，不采集真实系统状态。

Use only locally supplied metadata. PR1 implements the Offline Mode policy model only: no networking, uploads, or collection of live system state.

## Metadata Mode（未来占位）

仅在明确同意后发送最小、去标识化的软件元数据；禁止原始用户路径和文件内容。

Future placeholder: send only minimal, de-identified software metadata after explicit consent. Raw user paths and file contents remain prohibited.

## Cloud Deep Mode（未来占位）

需要逐次知情同意、目的限制、来源披露和可撤回机制。用户文档、代码、照片、浏览器 profile、凭据和密钥永不进入云端声誉检查。

Future placeholder: require per-use informed consent, purpose limitation, source disclosure, and revocation. User documents, source code, photos, browser profiles, credentials, and secrets never enter cloud reputation checks.

PR1 不包含任何联网功能，也不包含任何上传功能。

PR1 contains no networking or upload capability.
