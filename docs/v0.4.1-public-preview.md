# v0.4.1 Windows Integration Preview

这个版本让开发者和评审者可以从真实 Windows 只读 metadata 得到正式、默认脱敏、可验证的 PC CleanGuard report，而不需要手工拼接四个 JSON 文件。

用户显式运行 PowerShell collector 后，Python 负责：

1. 验证 collector manifest；
2. 规范化四类 metadata；
3. 生成 canonical raw/report 边界；
4. 默认写 redacted report；
5. 离线生成 PUP/no-match、持久化图、link diagnostics、治理计划和用户摘要。

这仍是 Windows Integration Preview，不是杀毒软件或自动清理器。它不运行采集到的命令，不因声誉或 AI 文本触发系统修改。真实系统动作没有在 v0.4.1 扩大。

Synthetic acceptance 只在 `%TEMP%\PC-CleanGuard` 专用空间验证隔离与恢复，因此仓库位于 Desktop 时也无需降低 Desktop 保护。
