# 产品定位 / Product Positioning

PC CleanGuard 是 AI Agent 的 Windows 清理治理安全层，不是追求“一键删干净”的传统 cleaner。它把扫描、证据、策略、用户确认、可恢复操作和审计拆开，让 Agent 的建议可见但不能越权。

当前大众可见价值：显式路径垃圾候选预览、空间估算、默认可恢复隔离、JSONL 审计、Markdown 报告、Developer Guard，以及 evidence-only PUP 线索。

核心差异：不静默删除、不联网或上传用户数据、不把 AI/社区/声誉单一来源当成执行授权，并为确认操作提供 manifest 和恢复入口。
