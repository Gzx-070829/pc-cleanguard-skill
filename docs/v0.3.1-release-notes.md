## Safety boundaries

Reputation、Evidence、PUP insight、Behavior Indicator 和中文来源矩阵全部只用于解释、排序与人工复核。它们不是删除、卸载、禁用或注册表修改授权；`execution_gating_eligible_count` 固定为 0。运行时不联网、不上传、不写爬虫，也不读取 API key。
