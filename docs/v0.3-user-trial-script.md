# v0.3 用户试用脚本

1. 查看版本：`python -m pc_cleanguard.cli --version`。
2. 运行 dry-run：`python -m pc_cleanguard.cli trial run --root .pcg-demo --output .pcg-trial`。
3. 打开 `.pcg-trial/START_HERE.md`，依次阅读用户摘要、cleanup report、PUP insight 和 audit。
4. 如需体验恢复链路，换新 root/output 并运行确认隔离命令。
5. 使用 `quarantine list` 获取 item ID，再运行 `python -m pc_cleanguard.cli quarantine restore --root .pcg-quarantine --item-id <id>`。
6. 单独查看 PUP 线索：`python -m pc_cleanguard.cli pup inspect --input <report.json> --seed examples/reputation/seed_records.zh-CN.json --output pup_insight.md`。

预期：默认不改动候选；confirm 后默认 quarantine；PUP 命中只用于解释。不联网、不上传、不静默删除，且不替代杀毒软件。
