# PC CleanGuard v0.1.0 Release Checklist

本清单用于 v0.1.0 Public Preview 的最终发布门禁。PR11 只准备发布材料，不创建 tag。

This checklist is the final gate for the v0.1.0 Public Preview. PR11 prepares the release but does not create a tag.

## 1. 范围 / Scope

- [x] Public Preview 仅包含只读分析、治理建议、dry-run 审计、离线解释和非执行 plan。
- [x] 不包含删除、卸载、隔离、禁用、服务/任务/注册表修改能力。
- [x] 不包含真实 AI provider、网络请求、上传或环境凭据读取。
- [x] Python 不自动执行 PowerShell collector。

## 2. 公开入口 / Public interfaces

- [x] CLI `scan` 有可运行快速开始。
- [x] CLI `explain` 有 Mock 和 dry-run prompt 文档。
- [x] 五个 Skill actions 有 JSON request 示例。
- [x] Action response 包含 confirmation、Level 0、evidence 和非授权字段。
- [x] JSON Schemas 覆盖 scan/report/audit/action/cleanup plan 契约。

## 3. 文档与示例 / Documentation and examples

- [x] README 中文优先，包含快速开始与安全边界。
- [x] `SKILL.md` 说明 action 选择、输入传递和禁止行为。
- [x] Public Preview 范围、局限和反馈渠道已记录。
- [x] 示例仅使用虚构名称和显式本地路径。
- [x] 审计示例保持 `dry_run=true` 且不包含命令。

## 4. 验证 / Validation

- [ ] 在候选发布 commit 上运行 `python -m compileall pc_cleanguard`。
- [ ] 在候选发布 commit 上运行 `python -m unittest discover -s tests`。
- [ ] 在候选发布 commit 上运行 `git diff --check`。
- [ ] 确认 `git status --short` 为空。
- [ ] 运行危险 API、进程/网络 import 和环境凭据名称搜索。
- [ ] 运行 Public Preview skill action examples 验证。

## 5. 发布决策 / Release decision

- [ ] PR11 已审查并合并到 `main`。
- [ ] `main` 与 `origin/main` 一致且工作树干净。
- [ ] 版本号、release notes 和最终 commit 已人工确认。
- [ ] 明确的人工批准已授权创建 `v0.1.0` tag。
- [ ] tag 创建后重新确认只读边界和发布产物。

Tagging remains a separate, explicitly authorized task. Do not infer tag authorization from this checklist.
