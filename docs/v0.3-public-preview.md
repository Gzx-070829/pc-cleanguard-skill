# PC CleanGuard Skill v0.3.0 Public Preview

v0.3.0 把安全治理能力包装成普通用户能运行和理解的体验：五分钟 trial、`clean safe`、默认隔离、恢复、Developer Guard、PUP insight 和 AI/Skill actions。

```console
python -m pc_cleanguard.cli trial run --root .pcg-demo --output .pcg-trial
```

默认是 dry-run。确认试用未提供 quarantine root 时自动使用 `.pcg-quarantine`，L1 文件进入可恢复隔离区：

```console
python -m pc_cleanguard.cli trial run --root .pcg-demo --output .pcg-trial-confirm --confirm --quarantine-root .pcg-quarantine
python -m pc_cleanguard.cli quarantine restore --root .pcg-quarantine --item-id <id>
```

PUP insight 通过本地 seed 提供解释和人工复核线索。Reputation 命中不是删除授权，也不是卸载或禁用授权。

PR24 Evidence Pack 将 mapping relation 和 synthetic 状态分轴表达；类比行为必须说明依据。MIIT APP/SDK 通报是移动端监管证据，不是 Windows 桌面软件删除名单；批次标签是滚动事实，不是稳定 taxonomy。

当前限制：不卸载软件、不修改注册表/启动项/服务/计划任务，不自动扫描全盘。PC CleanGuard 不替代杀毒软件或恶意软件应急响应工具。不联网、不上传、不静默删除。
