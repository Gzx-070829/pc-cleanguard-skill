# v0.4 Roadmap

1. 扩展可审计的中文 Windows evidence 生态。
2. 增加浏览器主页、搜索和扩展的只读检测。
3. 增强启动项、计划任务和服务的只读行为采集。
4. 识别官方卸载器，但不自动卸载。
5. 编写 L2 reversible actions 设计草案。
6. 编写 Registry backup / restore 草案。
7. 推进 Agent integration preview。
8. 探索 GUI / TUI 可视化。
9. 建立真实用户反馈和误报回流。
10. 不进入自动杀软路线。

v0.4 优先只读检测、可逆操作、用户确认和恢复；PUP evidence 仍不能单独触发执行。
