# 中文公开来源的限制

- 历史榜反映特定年代、版本和商业关系，不能当现代 Windows 删除名单。
- 安全厂商公开文章只提供公开行为描述；PC CleanGuard 不采集专有签名、规则库、检测逻辑或样本库。
- 官方移动 APP/SDK 通报可解释用户权益行为，但不能识别 Windows 软件。
- 单篇媒体报道需要原始材料和本机证据交叉核验。
- 社区反馈、网友名单、hosts/域名屏蔽表只能 candidate-only；域名不是软件身份。
- 下载站或推广器问题不能自动映射为软件本体、发布者全部产品或用户本机安装。

中文公开来源矩阵不是杀毒引擎，也不替代 Microsoft Defender。它不联网、不上传、不静默删除，且 `execution_gating_eligible_count=0`。
