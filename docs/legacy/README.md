# Legacy / Compatibility Capabilities

v0.1-v0.4 capabilities remain available for research, compatibility, and
historical reproducibility, but are no longer the product core.

This includes read-only Windows collectors/reporting, cleanup preview and the
bounded legacy L1 executor, quarantine/restore, PUP and reputation review,
evidence tooling, behavior indicators, persistence graphs/plans, public demos,
trial flows, AI explanation mocks, and the original broad Skill actions.

The final A/B result remains authoritative: Bare Codex 87.3, Codex + PC CleanGuard
89.5, delta +2.2; the broad route is `FEATURE_FROZEN`. Compatibility maintenance
must not expand execution scope or reinterpret intelligence as authorization.

Legacy CLI commands remain discoverable below the primary `guard` command. Their
machine JSON remains on stdout; compatibility notices belong on stderr. Historical
reports, showcase assets, and real-machine validation are retained unchanged.
