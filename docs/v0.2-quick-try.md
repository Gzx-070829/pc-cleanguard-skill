# PC CleanGuard v0.2 Quick Try / 五分钟公开试用

PC CleanGuard v0.2 把垃圾候选扫描、空间预览、默认 dry-run、受控 L1 清理、JSONL 审计和 Markdown 报告串成一个可运行闭环。所有命令均从仓库根目录运行，仅使用 Python 标准库。

## 最快方式：一条命令完成安全 Demo

```powershell
python -m pc_cleanguard.cli demo quickstart --root .pcg-demo --output .pcg-demo-output
```

`demo quickstart` 只初始化合成 demo root 并运行 dry-run，不提供确认参数，也不会删除文件。输出目录包含 `preview.json`、`dry_run_result.json`、`audit.jsonl` 和 `cleanup_report.md`。

## 分步体验

```powershell
python -m pc_cleanguard.cli demo init-cleanup --root .pcg-demo
python -m pc_cleanguard.cli demo run-cleanup --root .pcg-demo --output .pcg-demo-output
```

打开 `.pcg-demo-output\cleanup_report.md` 查看候选、预计可释放空间、would-clean、skipped 与 blocked 汇总。

## 在显式路径上预览与生成报告

```powershell
python -m pc_cleanguard.cli clean preview --path C:\Explicit\Temp --output output\preview.json
python -m pc_cleanguard.cli clean execute --preview output\preview.json --allow-root C:\Explicit\Temp --result output\result.json --audit output\audit.jsonl
python -m pc_cleanguard.cli clean report --preview output\preview.json --result output\result.json --output output\cleanup-report.md
```

以上 `clean execute` 没有 `--confirm`，所以只产生 `would_clean`。如果用户在审阅 preview 后选择真实 L1 清理，必须显式追加 `--confirm`；它仍只允许 allow-root 内重新验证通过的 temp/cache/log 普通文件，并强制写审计。crash dump、installer leftover 与目录候选继续跳过。

## AI / Skill 解释链路

```powershell
python -m pc_cleanguard.cli explain --report examples\reports\pr7_readonly_scan_pipeline_report.json --output output\explanation.md --provider mock
```

Mock explainer 离线运行，只解释治理报告，不构成清理授权。完整 Agent 编排示例见 [`examples/skill_actions/v0.2_cleanup_agent_flow.json`](../examples/skill_actions/v0.2_cleanup_agent_flow.json)。

## 安全边界

- 不自动扫描全盘，不自动发现清理 root。
- 不处理用户文档、桌面、图片、视频、代码仓库、浏览器 profile 或系统目录。
- 不卸载软件，不禁用启动项/服务/计划任务，不调用 PowerShell 或 subprocess。
- 不联网、不上传；AI 建议、候选和报告都不是执行授权。
- demo quickstart 永远 dry-run；真实 L1 清理只能通过显式 `clean execute --confirm` 或已标记 demo root 的受控执行路径。
