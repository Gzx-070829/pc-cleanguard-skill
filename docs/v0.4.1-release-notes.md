# PC CleanGuard Skill v0.4.1 Windows Integration Preview

v0.4.1 closes the gap between the existing read-only Windows collectors and PC CleanGuard's offline governance pipeline.

## Highlights

- Windows PowerShell 5.1 and PowerShell 7 compatible collector orchestrator and doctor.
- Structured manifest, partial collector status, errors, and UTF-8 no BOM artifacts.
- Canonical Windows report builder reusing the existing installed app, startup, service, and scheduled-task models.
- Default irreversible redaction for user names, home paths, device names, email addresses, UNC identity paths, and token-like strings.
- Safe raw-report opt-in requiring an explicit sensitive-data acknowledgement.
- Offline Windows evaluation producing PUP review, persistence graph, governance plan, link diagnostics, and user-facing summaries.
- Dedicated temp synthetic acceptance workspace with nonce, manifest, SHA-256, quarantine, restore, and audit checks.
- Link diagnostics explain zero-edge results and reject publisher-only or weak-name clues as strong entity links.

## Safety boundaries

- Python never launches PowerShell collectors.
- Collector metadata is never executed.
- Process-level `ExecutionPolicy Bypass` does not modify user or machine policy.
- No network access, upload, uninstall, registry write, startup/service/task disable, or new permanent-delete mechanism.
- Desktop, Documents, repositories, browser profiles, and Developer Guard protections remain unchanged.
- PUP evidence and persistence relations remain review-only with `execution_gating_eligible_count=0`.
- A 0 PUP match or 0 persistence edge is a valid result, not proof that a machine is clean.

See `docs/windows-real-machine-quickstart.md` for the supported two-step flow.
