# PC CleanGuard Skill v0.3.1 Public Preview

v0.3.1 让中文 PUP 公开来源变得可追溯、可分层、可审计。来源先进入本地 JSON 契约，再根据来源类别进入 candidate、review hint、explanation 或 historical context；不会因“来源看起来可信”直接生成系统动作。

核心入口：

```powershell
python -m pc_cleanguard.cli trial run --root .pcg-demo --output .pcg-trial
python -m pc_cleanguard.cli reputation cn-source stats --input data/reputation/cn_source_matrix.zh-CN.json
```

PUP Review Pack 可以展示来源矩阵、候选状态、第二来源要求和对抗守卫。所有输出都在本地生成；PC CleanGuard 不是杀毒软件，也不替代 Microsoft Defender 或其他安全工具。
