# Legacy and Optional Intelligence

PUP, Reputation, Behavior Indicators, Evidence Quality, Corroboration,
Persistence Graph, and Windows collectors remain available for explanation,
review, ordering, and historical reproducibility.

They may produce `RiskSignal`, review hints, target facts, or evidence references.
They cannot produce Consent, `ALLOW`, or an `ExecutionContract`. Guard Core does
not import these modules. Deleting every Reputation/PUP record or the entire
Persistence intelligence layer leaves Guard operation intact.

See [docs/legacy/README.md](../legacy/README.md) for compatibility status.
