# v0.5.0 Re-foundation Decision

Status: **Accepted**  
Date: 2026-08-14

## Historical finding

The v0.4.x product hypothesis was that a broad Windows cleanup, PUP, reputation,
and persistence Skill would create enough independent value beside a general AI
agent. The final controlled comparison did not establish that claim:

| Variant | Score |
| --- | ---: |
| Bare Codex | 87.3 |
| Codex + PC CleanGuard | 89.5 |
| Delta | +2.2 |

The original route remains `FEATURE_FROZEN`. The scores, rubric, evidence,
instances where Bare Codex won, and the negative product conclusion are immutable
historical records. See
[PC-CleanGuard-Final-AB-Evaluation.md](../PC-CleanGuard-Final-AB-Evaluation.md).

## Decision

PC CleanGuard v0.5.0 is a new, narrower product hypothesis:

> PC CleanGuard is a deterministic governance guard for AI agents performing
> real Windows system actions.

> PC CleanGuard 是位于 AI Agent 与 Windows 系统操作之间的确定性治理层。

The core governs five things: Policy, Consent, Preconditions, Audit, and
Rollback. It converts a structured action request into a deterministic decision
and, only after every required gate is independently satisfied, an execution
contract for an external executor.

## Non-negotiable boundary

- An Agent may propose an action but cannot authorize itself.
- Natural-language reasoning is explanatory data, never authorization.
- Reputation, PUP, behavior, evidence, confidence, and persistence signals are
  untrusted intelligence. They may make a decision more restrictive, never less.
- A user consent grant cannot override a hard block.
- The Guard does not execute shell, PowerShell, uninstall, registry, service, or
  scheduled-task operations.
- The integrating host is responsible for authenticating consent and routing
  relevant operations through the Guard.

## Consequences

The v0.1-v0.4 functionality remains available for compatibility and historical
reproducibility, but it is no longer the product core. We do not delete or rewrite
that history. New product work must demonstrate governance value and must not
restart the frozen Cleaner/PUP-first roadmap.
